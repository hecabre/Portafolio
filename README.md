# Aaron Hernandez — Portfolio

Landing de una página hecha con Astro, GSAP y Lucide.

## Desarrollo

```bash
npm install
npm run dev
```

## Deploy en Vercel

Sube esta carpeta a un repositorio de GitHub e impórtalo en Vercel. Vercel detecta Astro automáticamente; usa `npm run build` como comando de build y `dist` como directorio de salida.
